Vehicles App – Exploración de precios de autos usados

Objetivo: Analizar precios de autos usados para facilitar decisiones de compra/venta.
Herramientas: Python (pandas, Plotly Express), Streamlit, Render.
Resultado: Desarrollo de una aplicación web interactiva con filtros dinámicos que permite comparar precios y atributos en tiempo real.
